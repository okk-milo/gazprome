# gazprome

## Страницы

- `/#antifraud` (и `/`) — реальная загрузка и история анализа звонков через gazprom-api.
- `/#burnout` — восстановленный демонстрационный шаблон выгорания из `130d6b0`: прежний пример сотрудника, оценка 64, восемь недель динамики, шкалы, нагрузка, основания и рекомендации. Все значения статические и явно помечены как демоданные; страница не запрашивает анализ и не связана с БД или загруженными звонками.

При переключении страниц выбранный звонок и состояние формы антифрода сохраняются. Прямая ссылка на выгорание не загружает справочники антифрода до перехода в этот раздел. Стили шаблона ограничены `.burnout-demo`.

Проверки: `node --test tests/*.test.mjs`, `npm run build` (vue-tsc и Vite).
