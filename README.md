# gazprome

Веб-интерфейс системы анализа телефонных разговоров: оценка риска мошеннического воздействия и просмотр показателей состояния сотрудников

Актуальная реализация: [ветка task/DEV-614](https://github.com/okk-milo/gazprome/tree/task/DEV-614)

## Возможности

- Загрузка аудиозаписей с привязкой к сотруднику и сделке, просмотр истории проверок
- Отображение хода обработки, расшифровки с ролями участников и динамики оценки риска по шкале 0-100
- Просмотр оснований, повышающих и снижающих оценку риска
- Отдельный раздел «Выгорание» с показателями состояния сотрудника и их динамикой

## Технологии и взаимодействие

Стек: Vue 3, TypeScript, Vite

Интерфейс получает данные через [gazprom-api](https://github.com/okk-milo/gazprom-api/tree/task/DEV-614); распознавание речи и языковой анализ выполняются отдельными серверными сервисами, промежуточные результаты отображаются по мере обработки записи

## Качество и ограничения

На внутренней выборке ROC AUC оценки выгорания составил около 0,87; выборка защищена условиями NDA

*В выборке исходных датасетов часть аудиозаписей содержит заглушенные речевые фрагменты, что снижает разборчивость речи и полноту доступного контекста, ограничивая возможности автоматического анализа и оценки его качества*
